Feature: before/after table-summary across two DB loads (branch zfin-compare-db-loads)

Goal: given two dated DB unload files, load each via `gradle loaddb`, snapshot every
table (row count + content hash), and emit a per-table before/after comparison summary.
Driven automatically by a Jenkins job that mirrors Load-Database's file selection.

Design note: snapshot hashes each row then aggregates in hash order (ORDER BY the
row's own md5), NOT by PK/all-columns. This is deterministic, key-agnostic, and
avoids ORDER BY failures on PK-less tables with unorderable column types (json/xml).
