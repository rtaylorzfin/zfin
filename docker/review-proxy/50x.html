This host runs ZFIN feature stacks, one per ticket, each at its own URL.

The stack you asked for does not exist here, is not running, or has been frozen. If someone sent you this link, ask them to bring it back up — it takes a couple of minutes.

If you have the tooling

./z feature ls                 # every stack on this host, and its state
./z review status              # the proxy, its allowlist, and what it routes

To bring one back, or create it

./z feature thaw <ticket>      # restore a frozen stack
./z feature new <ticket> --up  # provision a new one from a seed

If a stack should be here but isn't reachable

docker ps --filter name=<ticket>
./z review status              # is its hostname listed under routed vhosts?

A stack joins the proxy when it is created; routing is not retrofittable to a stack made before it. See reference/dev-stacks.md.
